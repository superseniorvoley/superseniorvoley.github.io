DATOS ABIERTOS

API pública

Los datos del torneo, en JSON y de solo lectura. Sin registro ni clave: se pueden leer desde cualquier web.

← Volver a la portada
▣

Cómo usarla

Dirección base: https://superseniorvoley.github.io/api/v1/ · La temporada en curso cuelga de la raíz y cualquier otra, de /AAAA-AA/ (p. ej. /api/v1/2025-26/clasificacion.json). Los campos siguen el contrato de datos y cada respuesta lleva su version; si el formato cambia de forma incompatible, se publica una versión nueva (/v2/).
