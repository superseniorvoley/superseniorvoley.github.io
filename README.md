# Liga Super Senior — V2
Versión visual/funcional de prueba para la temporada 2026/27.

## Modelo
- Una jornada = un día de competición.
- Cada jornada admite Cancha 1 y Cancha 2.
- Cada cancha admite varios horarios/partidos.
- Los partidos guardan los tres sets individualmente.
- La clasificación se calculará automáticamente según el reglamento.

## Publicación
GitHub Pages desde la rama `main`, carpeta raíz `/`.

Los equipos, fechas y resultados visibles son datos de prueba. La siguiente fase conectará la web con una hoja de datos.
